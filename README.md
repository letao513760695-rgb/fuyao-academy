# 扶摇学院 · 数字课件中心

> 道术兼济，鲲鹏天下。

全中文、适配电脑和手机的培训课件平台交互原型。使用 React 19、TypeScript、Vite、React Router 和 Lucide 图标。插画为项目内的 SVG，不依赖外部图片、字体或付费服务。

## 本地运行

快速体验：构建后的 `dist/fuyao-academy-preview.html` 是自包含体验版，可下载后尝试在桌面 Chrome 或 Edge 中直接打开，不需要安装 Node.js。它与开发服务使用不同的本地存储空间。该文件已通过本地 HTTP 与断网交互验证；云端受管理浏览器禁止 `file://`，未在云端验证双击打开。若浏览器限制本地文件，请使用下面的开发服务方式。

需要 **Node.js 22.12+（推荐 Node.js 24）** 和 npm。在项目目录运行：

```bash
npm ci
npm run dev
```

在运行命令的电脑上，浏览器访问 `http://localhost:5173`。服务默认监听 `0.0.0.0:5173`，方便在支持端口转发的工作区中预览；这不是公网部署。仅需本机监听时使用：

```bash
npm run dev -- --host 127.0.0.1
```

当前云工作区路径为 `/workspace/fuyao-academy`。云机器的 localhost 不等于你的电脑；在本机测试时，请将项目下载到本机执行以上命令。若工作区支持端口转发，可转发 5173 端口。

构建和预览正式产物（仍只在本地运行）：

```bash
npm run build
npm run preview -- --host 127.0.0.1
```

预览端口默认为 4173。按 `Ctrl+C` 停止对应服务。

重新生成单文件体验版：`npm run build:standalone`。该文件内嵌全部界面代码、样式和插画，可离线浏览。上传的 PDF 仍由浏览器原生阅读器处理。

## 第一版功能

- 首页：品牌介绍、关键词搜索、分类入口、精选课程和最新更新。
- 课程中心：六个初始分类、搜索、组合筛选、收藏、排序、网格/列表切换与空结果提示。
- 课程详情：介绍、适用人群、学习目标、章节目录、资料与相关推荐。
- 阅读器：模拟 PDF/PPT 转换后的课件，支持翻页、章节导航、指定页码、方向键、全屏和自动保存演示阅读进度。
- 访问演示：产品知识、合规教育课程默认需要密码。统一演示密码 **`fuyao2026`**，验证在当前浏览器会话内保留。
- 管理工作台：增删改课程、上传资料、选择封面、调整分类与顺序、设置精选、密码访问和下载开关。
- 资料：PDF 使用浏览器原生阅读器；PPT/PPTX 保存原文件但不转换，阅读页显示演示内容。可点击和拖拽上传，单文件不超过 20 MB。

## 建议体验路径

1. 首页搜索“钱币”，再切换分类、收藏课程、切换列表视图。
2. 打开《走进东方金典》，进入阅读器，用目录、页码或键盘方向键翻页，返回后继续学习。
3. 打开《第四套人民币收藏知识》，先尝试错误密码，再输入 `fuyao2026`。
4. 管理工作台新增课程，刷新验证内容仍然存在；修改分类和下载开关，再到前台查看变化。
5. 上传非敏感 PDF 体验原生预览，或上传 PPT 体验保存原件和演示阅读流程。
6. 手机尺寸下检查导航、分类横向滚动、详情与阅读器抽屉目录。

## 数据与限制

**没有服务器、数据库、真实身份认证或安全保护。** 管理入口开放，前端密码可被绕过，下载开关仅控制界面入口。请勿上传机密、个人敏感资料或需要真实授权保护的文件。

- 初始课程及章节是模拟数据，不是正式教材。
- 课程、分类、收藏及演示阅读进度位于 `localStorage` 的 `fuyao-academy-v1`。
- 已验证课程记录位于 `sessionStorage` 的 `fuyao-unlocked`。
- 上传文件位于 IndexedDB `fuyao-files`，不会发送至服务器。
- 不同浏览器、来源地址或设备之间不共享数据；清除站点存储会丢失本地修改和文件。
- PDF 实际页数、翻页和全文检索由浏览器阅读器管理；表单页数是模拟课件页数，原生 PDF 阅读进度不会自动保存。
- PPT 不支持转换或真实内容预览；允许下载时可下载原件，用本机软件打开。
- 初始课程下载为明确标注的 **HTML 演示讲义**，可在浏览器打开或打印，并非 PDF/PPT 文件。
- 如需重置，可在开发者工具中清除此站点的 localStorage、sessionStorage 和 IndexedDB，恢复初始演示内容。这会删除你的本地修改。

## 扩展结构

| 文件                 | 责任                                        |
| -------------------- | ------------------------------------------- |
| `src/data.ts`        | 数据类型、六门种子课程及演示课件            |
| `src/services.ts`    | 数据仓库接口、本地存储和 IndexedDB 文件访问 |
| `src/store.tsx`      | 共享状态、收藏、进度、访问会话与提示        |
| `src/Browse.tsx`     | 首页、课程中心和学习指南                    |
| `src/Course.tsx`     | 详情、密码页、阅读器和下载                  |
| `src/Admin.tsx`      | 课程编辑、上传和分类管理                    |
| `src/Art.tsx`        | 本地 SVG 插画                               |
| `src/components.tsx` | 共享界面组件                                |
| `src/styles.css`     | 响应式布局、主题和动效                      |

后续可将 `AcademyRepository` 替换为异步 API 仓库，将文件读写接口替换为云存储，并在服务端实现登录、课程授权、下载签名、审计和 PPT 转换。当前前端密码逻辑不能作为生产认证基础。

使用 Hash 路由；无需付费服务、云存储或正式数据库。用户已授权将演示原型发布到公网；发布权限、Pages 配置和公开访问需分别核实，构建成功不代表网站已上线。

## 免费静态托管准备

```bash
npm run build:pages
```

`pages-dist/` 包含用于静态托管的生产版 `index.html`、`404.html`、`.nojekyll` 和图标。页面内嵌全部代码和样式，兼容 GitHub Pages 的仓库子目录地址。发布时只上传此目录，不包含本地浏览器中的课程修改或上传资料。

公开体验地址：https://letao513760695-rgb.github.io/fuyao-academy/

当前 GitHub Pages 的发布来源为 **`main` 分支的 `/(root)`**，已完成首次发布。`main` 中保存可直接托管的网页成品，完整 React/TypeScript 开发源码保存在 **`prototype/fuyao-academy-v1`** 分支；`gh-pages` 保留了之前准备的发布文件，当前不作为发布来源。

更新网站时，在开发分支执行 `npm run build:pages`，将 `pages-dist/` 的四个文件同步到 `main` 后正常提交推送，等待 GitHub 的 `pages build and deployment` 成功，并检查公开网址。不需要切换 Pages 设置；保留远程已有提交和其他文件，不使用强制推送。

公共体验版的管理入口也公开，但所有人只修改自己浏览器中的演示数据，不影响其他访问者。
